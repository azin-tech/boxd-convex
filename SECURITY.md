# Security

Please don't report security problems in public issues.

Report them privately through
[GitHub's vulnerability reporting](https://github.com/azin-tech/boxd-convex/security/advisories/new),
or email [contact@boxd.sh](mailto:contact@boxd.sh). Include what you found, how
to reproduce it, and the version of `@boxd-sh/convex` you use. We'll confirm we
received it and keep you posted while we fix it.

## Supported versions

Fixes go into the latest release.

## Scope

This repo holds the `@boxd-sh/convex` component, a reference app
(`example/convex`) and the public demo (`demo/`). Issues in boxd itself, such as
the API or the machines, can go to the same addresses.
